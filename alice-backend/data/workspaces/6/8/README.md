# Reminder App

A Windows reminder application that integrates with Home Assistant via MQTT.

## Features

- Create and manage reminders through a simple GUI
- Send reminders to Home Assistant via MQTT
- Receive reminders from Home Assistant
- Mark reminders as acknowledged
- Priority-based reminders (Low, Medium, High)

## Requirements

- Python 3.8 or higher
- Tkinter (usually included with Python on Windows)
- paho-mqtt
